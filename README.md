# StudyHub

## Project Description

StudyHub is a web application designed to help students organize their academic activities, manage tasks, and track deadlines.

The project is developed as part of the course "Web Technologies and Web Design".

## Technologies

- React
- Vite
- JavaScript
- CSS Modules
- ESLint
- Stylelint
- Git
- GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/nikitakupin-ops/studyhub-web-project.git
```

Navigate to the project directory:

```bash
cd studyhub-web-project
```

Install dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

## Code Validation

JavaScript validation:

```bash
npm run lint
```

CSS validation:

```bash
npm run stylelint
```

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
